# AI 视频提示词撰写规范（基于《地狱磨砺》方法论）

把一段故事/一个镜头，转化成能让视频模型稳定出片的提示词。核心心法：

- **把容易出错的地方提前拆成可锁定的规则、写进提示词**
- **每段提示词只承担一个主要动作**
- **一次只改一个变量，重新生成并对比，直到结果稳定**

---

## 使用时机（何时触发本规范）

- 用户要「生成一段视频的提示词」「写分镜提示词」「设计镜头运动」
- 用户要「为 AI 电影/短片写脚本提示词」「把某个画面/情节拍出来」
- 用户要「优化视频出片一致性」「解决角色脸/服装/道具乱变、空间跳、动作不自然、灯光漂移、人数错误」等问题
- 用户提到 Seedance、Sora、可灵、Runway 等文生视频/图生视频模型

## 工作流总览

严格按创作顺序推进，不要跳步：

```
① 资产准备（先做参考图资产） → ② 场景与空间（定场、定坐标系）
→ ③ 角色表演（写表演主档案） → ④ 逐镜提示词（套框架 + 贴风格预设）
```

> 原则：前期只锁定「资产外观」，不写镜头调度；后期每新增一类风险（空间、动作、物理、灯光、声音），就往提示词里补一条对应的锁定规则，逐镜逐步加严。

## 预期管理

- 提示词写到几千字，最后仍可能抽到废片。真正提成功率的做法是：把易错点提前拆成可锁定的规则；一次只改一个变量重新生成；一个镜头仍不行就拆成两个镜头或换机位角度。
- 素材生成只是第一步，成片还需生成→筛选→重做→清理→剪辑→调色。
- 不必照搬 50 万美元规模，可以从一分钟小故事或三五分钟短片开始。
