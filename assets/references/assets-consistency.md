# 第一阶段：资产与一致性（规则 1–8）

视频模型最常见的翻车点：脸/衣服/道具突然变、空间位置乱跳、人物数量错。解决办法是在**生成视频之前**先把「固定资产」做出来。

## 规则 1：先生成参考图，再开始生成视频

在开始生成视频之前，先为会反复出现的人物、场景和关键道具生成参考图，做成固定资产，让后续每一个镜头都能精准指向同一资产。

## 规则 2：一套资产 = 参考图 + 固定描述（缺一不可）

- **参考图**：告诉模型「长什么样」。
- **固定描述**：告诉模型「哪些特征必须维持一致」。
- 把这段固定描述**逐字逐句、一字不改**地放进每一段相关的视频提示词中。

## 规则 3：角色参考图三件套

每个角色至少准备三张图：**一张清晰脸部、一张正面全身、一张背面全身**。
- 脸部图提供脸部细节；全身图提供体型与衣服结构。
- 组合使用时，把正面全身图的头部裁剪/遮盖掉，只保留清晰脸部图作为**唯一脸部来源**，避免模型从全身图抓到模糊、失真的脸。

## 规则 4：角色参考图只用中性材质

角色参考图一律使用**中灰背景 + 平行光 + 真实皮肤纹理**，不提前加入电影调色或场景灯光。资产做得越朴素，越能适配后续任意场景与灯光。

## 规则 5：状态变了，就拆成独立资产

同一个角色/场景/道具只要状态发生明显变化，就各自独立成资产：

| 对象 | 应拆分的状态资产 |
|------|------------------|
| 角色 | 普通状态 / 淋雨 / 受伤 / 不同服装 |
| 场景 | 白天 / 夜晚 / 雨天 |
| 道具 | 在不同场景下的不同状态 |

在生成参考图阶段就把这些状态资产全部做好。

## 规则 6：道具四重锁定

道具除参考图外，靠**固定名称 + 外观描述 + 数量 + 状态**在每一镜里反复锁定。示例：

> 训练室场景：「五个被损坏的人偶，绝不能重新生成成完整状态，绝不能增加数量。」

## 规则 7：微调只写改动点，其余严格保留

当一张图已接近完成、只需微调时：
- 只写本次要改的**那一处**；
- 其余元素（人脸、衣服、构图、光线、阴影）写清「严格保留、与上一版完全一致」；
- 同一张图尽量只改**一轮**，多跑一轮都可能产生纹理损失或色彩漂移。

## 规则 8：明确参考图用途，统一资产命名

把参考图喂给视频模型时，必须写明用途：
- 角色图只负责**角色参考**；
- 场景图只负责**空间和纹理**，可明确写「不要继承它的构图、机位和调色」；
- 所有资产命名从文档到提示词**统一**，避免同一资产出现不同叫法。
