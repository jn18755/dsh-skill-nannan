# 第二阶段：场景与空间关系（规则 9–12）

## 规则 9：场景参考图优先用 3/4 视角

场景参考图优先用 **3/4 视角**，让模型同时看见前后左右的空间关系和场景纵深。准备场景图时，尽量按后面真正会拍到的机位去生成。

## 规则 10：给每个场景绑定一个不变参照物

每个场景选一个**长期不变的参照物**（一根柱子、一盏灯、一张沙发），再把人物调度和它绑定。示例：

> 「人物站在灯旁，面向房门。」

静态对白戏可以只给模型一个**房间角落**的场景参考，减少它随意安排站位。

## 规则 11：反打镜头先生成反向视角

反打镜头要先生成**同一场景的反向视角图**，并明确写出反向视角中每个主要物体的**新位置**。

备选方法：让 Seedance 生成一段在**空场景中缓慢穿行**的视频，截取需要的角度，再交给图像模型补纹理和光线等细节。

## 规则 12：复杂场景单独写「空间布局平面描述」

复杂场景单独写一份空间布局平面描述：**只描述地点本身，不写人物和动作**。空间位置统一用「画面左侧 / 画面右侧」这类摄影机视角能理解的坐标，再配合具体地标和距离。示例：

```
GEO SPATIAL LAYOUT（空间布局）：
— PLATFORM（平台）= 位于悬崖边缘、抬高的圆形仪式石台。
— ALTAR-MONOLITH（祭坛巨石）：位于悬崖边缘，相对平台处于画面中间偏右位置。
— RITUAL CENTER（仪式中心）：画面中间偏左位置，距离祭坛约 3 米。
— 180° AXIS（180° 轴线）：摄影机始终位于角色倒地的一侧——绝不越过轴线。
— BACK-LIGHTING（背光）：深红色地平线光芒来自平台后方，为剪影勾出轮廓光。
```
