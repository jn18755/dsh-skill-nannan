# 第三阶段：角色表演设计（规则 13–20）

## 规则 13：为每个长期角色写一份固定的「表演主档案」

给每个长期角色各写一份固定的表演主档案，提前设计好身体节奏、习惯动作、眼神、声音，以及在不同状态下的变化。示例（VIKTOR 表演主档案）：

> VIKTOR：六十岁出头的男性，退休的夜班出租车司机，曾是业余拳击手；体格厚重、脖颈粗壮，中段已经发福，鼻梁扁平，两侧眉骨都有旧伤疤；无论坐着还是站着，重心都低而稳，重量始终完整落在整个脚掌上。他只有一个核心驱动力：几十年等待乘客、等待回合、等待麻烦的生活，让耐心变成了他的武器。
> 声音特征：低沉、沙哑、不急不缓的男中低音，带着工人阶层式的粗粝感；句子短，表达平直、节省，事情越严重，声音越慢、越轻——他从不加快语速。
> 关键身体习惯与小动作：评估局面时，会让一枚旧硬币在指关节之间滚动；在说「不」之前，会缓慢而清晰地用鼻子吸一口气；当有人在他面前撒谎时，他会彻底静止，用长时间沉默施压；平时的脸是一张眼皮沉重、显得无聊的面具，实际上藏着完整的注意力。
> 眼神生命：困倦、半垂的眼睛，眨眼缓慢而刻意，持续安静地扫描后视镜、双手、出口；视线总会在头转过去前一个节拍先落到说话者身上；眼神高光很弱，但始终有生命。
> 步态风格：一种沉重、滚动感明显的「老拳手步」，步幅短而节省，双肩保持水平，双手放松但随时准备动作，从不赶路。
> 然而，当有人在他身边抬起手时，那张困倦的面具会在半秒内消失：下巴收低，双手抬到一半，双脚自动回到旧时的拳击站姿——随后他意识到自己的反应，又尴尬地把这一切收回去。只有面对流浪狗时，他的脸才会真正柔和下来；他会从外套口袋里拿食物喂它们。

## 规则 14：写行为，不写感受

写行为，不写感受。写清角色的**目标**和**障碍**，让角色在这场戏中不断改变行动方式。示例：

> 角色想得到某样东西，但有个人挡在他面前 → 他先开玩笑 → 没用 → 他开始施压 → 还是没用 → 他开始恳求。

## 规则 15：用物理动作代替情绪词

少写「愤怒」「悲伤」「筋疲力尽」这类情绪词，改写成**物理动作**，描述身体和肌肉具体发生了什么。示例（Roco 训练结束后）：

> Roco 站在训练垫中央，双脚大幅分开、牢牢踩地。胸口随着短而浅的呼吸快速起伏；水晶手臂沉重地垂在身体一侧，把他的右肩向下拖得比左肩低大约一根手指的高度。下颌绷紧、放松，重复两次；一缕血从鼻子流到上唇，他任由它继续流；一次慵懒眨眼，一次快速双眨，一次用力重置式眨眼。
> 视线落向画面中央偏右那些被损坏的人偶，停留一个节拍，然后随着门打开，视线抬向门口：眼睛先抵达门口，头才转过去。

## 规则 16：给角色安排「正在做的事」

给角色安排正在做的事（擦杯子、滑动平板电脑、整理装备），让人物一边做事一边说话；真正要强调某个瞬间时，让他**突然停下手里的动作**。示例（走廊戏）：

> 角色 Rein 一直在操作平板电脑，直到远处传来撞击声，她的手指先停住，随后抬头。

## 规则 17：多人戏给每个人不同的反应时间差

多人戏不要让所有人做出同样的反应，给每个人**不同的反应时间差**。示例（走廊戏）：

> 角色 Rein 先听到撞击声，停止滑动平板电脑并抬头；角色 Jax 笑容晚半拍才消失，并扭头寻找声源。这种时间差让角色更像各自在判断。

## 规则 18：允许角色抢在对方台词结束前给反应

角色可以在对方台词结束之前就开始给反应：听到关键信息时，先让**眼神和动作变化**，再停留一个很短的消化时间，最后才开口回答。

## 规则 19：单独写眼神戏

单独写眼神戏：给角色视线一个明确的目标，再加入微微的眼跳和不同节奏的眨眼；角色转头时，让**眼睛先追踪到目标，头部再紧接着跟上**。

## 规则 20：锁定声音与身份

声音和身份要锁定：每个主要角色固定一条声音提示词，规定音高、音色、口音、语速和说话方式；只要角色开口，就把同一条声音描述保持原样加入提示词。示例：

> 声音：低沉、沙哑的男声，介于低音和中音之间；语速缓慢、仿佛经过计算；伦敦街头口音；带着威胁感的平静——他从不提高音量。
